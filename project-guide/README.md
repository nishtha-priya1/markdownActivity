# Markdown Activity

## Overview

This project is to help students learn how and where they can use markdown. It's value comes from being able to learn something to use in different places.

## Features

- Track practice tasks with checkboxes.
- Organize daily learning with headings.
- Explain progress using mathematical expressions.

## Installation

Run these commands in a terminal to download this repository, then enter its folder:

```bash
git clone https://github.com/nishtha-priya1/markdownActivity.git
cd skills-communicate-using-markdown
```

Open `day-1.md` in your editor to confirm the journal is present. No build or dependency installation is required.

## Usage

From the repository folder, display the journal in a terminal with this command. On Windows PowerShell, use `Get-Content day-1.md` instead.

```bash
cat day-1.md
```

For formatted reading, open [the journal of changes](../day-1.md) on GitHub and select Preview when editing. Check or uncheck tasks by editing their Markdown and committing your changes.


## Prerequisites

Use a web browser to read the journal on GitHub. For a local copy, install Git and a text editor. A GitHub account with repository access is required to contribute.


## Expected output

The terminal displays the source Markdown of the file. The rendered Markdown is when you open a preview of a file.

```text
# Daily Learning

## Morning Planning
```

On GitHub, the same headings appear at different sizes and task markers become checkboxes.

## Contributing

You can create a branch in the repository and preview markdown and check links by clicking to open it within the browser. There's no way to run the tests for the journal, rather it's run by looking at the current actions. You can also do a pull request to get any new changed being made to the repo.
